# V3.0.9 – editable text effects

Based on the complete V3.0.8 ZIP. Deploy to the existing Worker without changing configuration.

Editor → TV / Phone → Typography → Text effects: None, Drop shadow, Outer glow. Select effect colour, opacity (0–100%), blur (0–60% of font size), horizontal/vertical offset (−30 to +30% of font size; shadow only). Both numeric fields and sliders are supported. Glow stays centred. The effect uses em units so the preview and display scale together. Existing text colours are not changed. TV effects apply to title, subtitle and additional text layers together; phone effects apply to branding text and card headings/body text, not voting buttons or images. Competition score cards retain their own design.

Presentation theme → TV typography / Phone typography: the same controls are available. Newly created slides inherit them; individual slide edits detach the changed values. Existing slides without these new inheritance keys stay unchanged. Use the typography group's Use theme control to link them (this replaces typography overrides for that group, not images). Existing presentations and votes do not require data migration. The existing editing lock during active interactions is unchanged.

Verification: all 11 existing Node suites, expanded theme persistence/validation/reload and TV/mobile renderer tests, and actual Chromium editor and theme controls/TV computed styles using mocked API. Physical device testing and deployed Cloudflare testing are not performed. No changes to score publishing or competition behavior.
