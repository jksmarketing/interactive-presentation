# V3.0.10 results update

## Changes
- Replaced fixed-pixel scoreboard overlays with canvas-relative layouts that reserve header and footer space. The phone scoreboard occupies the available space between branding and connection footer without nested cards or scrollbars.
- Identical live-render path for TV output and control preview. The original slide text/layers are hidden during the score reveal to prevent overlapping text; the slide background stays in place. Scoreboard colors retain independent contrast styling.
- Rankings show up to eight groups per page. Larger competitions automatically rotate through pages every eight seconds, synchronized using the server clock for newly published results. Long group names or competition titles may be abbreviated to fit. Groups without votes show a dash, not a zero score; tied exact averages share a rank.
- Manual and timed voting closure publish the current group's anonymous aggregate (mean, response count, counts for each rating value). No other groups' scores are newly exposed during this stage. The group result persists through reconnects, until the next round, dismiss, final reveal, competition switch, or leaving its slide. Leaving the slide early via navigation still follows existing cancellation/closure safeguards; it does not automatically show a result on unrelated slides. Group results take precedence over idle phone modes while displayed, but not over an active interaction or an ended participant session.
- Existing competition IDs, source links, stored votes, themes and storage binding remain unchanged. Newly stored round-result pointer is optional; older sessions load without it. No migration of stored scores is required.

## Verification
- `npm test` runs 12 suites including the new round-results backend tests.
- `python tests/results-dom.py` checks rendered bounds and overflow in isolated Chromium with actual app code and simulated state, including TV at 1920×1080 and 1280×720, phones at 320×568, 390×844, 650×998 and live controller at two desktop sizes. Tests include reveal, dedicated results, 10-value group distribution and 17-group paging.
- `python tests/mobile-dom.py` checks existing phone interactions and editor/controller features.
- Physical device, native browser versions other than Chromium, live Cloudflare network and TV refresh latency have not been tested. No claim of pixel-perfect rendering for arbitrary text lengths or every device. Use an isolated rehearsal copy and export the presentation before replacing production files.
