# V3.0.7 — Rating labels and early voting

- Competition rating scales use neutral numbered endpoints, `1 · Niedrig` and `<maximum> · Hoch`, consistent with standalone rating slides.
- Live control displays **Open voting now** during a running or paused competition countdown. Confirmation names the competition and group. Voting opens for that group, not the next group.
- The backend shares the normal and manual countdown-to-voting transition. It verifies the current competition, group, epoch, and countdown state. The original countdown is cleared and the configured voting deadline (if any) starts when voting opens.
- Automatic voting on countdown expiry remains available. No configuration or storage migration is needed.

## Verification
All eleven Node test suites and JavaScript syntax checks passed (see TEST-OUTPUT.txt). New checks cover the button's phase visibility, scale labels at 7 and 10, early voting while running or paused, authorization, stale/wrong-group requests, acceptance of votes, alarms and normal expiry.
